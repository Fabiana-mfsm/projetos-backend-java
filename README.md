# 🚀 Estudos e Práticas: Backend com Java & Spring Boot

Repositório centralizado para armazenar todos os estudos, códigos práticos, laboratórios e atividades desenvolvidas sobre o ecossistema **Java**, **Spring Boot**, uso da **IntelliJ IDEA** e construção de **APIs RESTful**.

---

## 🎯 Objetivo do Repositório
Servir como um portfólio de evolução e guia de referência rápida para os conceitos aprendidos na disciplina/estudos, cobrindo desde a configuração de ambiente e fundamentos do ecossistema corporativo até o desenvolvimento de aplicações robustas, escaláveis e conectadas a bancos de dados.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas
- **Linguagem:** Java (JDK atualizado / compatível)
- **Framework:** Spring Boot, Spring Web, Spring Data
- **Gerenciador de Dependências:** Apache Maven
- **Servidor Embutido:** Apache Tomcat
- **IDE:** IntelliJ IDEA
- **Banco de Dados / Persistência:** MongoDB / PostgreSQL (conforme a atividade)
- **Cliente de Testes HTTP:** Insomnia / Postman
- **Controle de Versão:** Git e GitHub

---


## 💡 Tópicos Cobertos ao Longo do Repositório
- **Configuração de Ambiente:** Uso correto de SDKs, compiladores na IntelliJ IDEA e geração de projetos via *Spring Initializr*.
- **Fundamentos do Ecossistema:** Inversão de Controle (IoC), Injeção de Dependências e ciclo de vida de aplicações Spring Boot.
- **Desenvolvimento de APIs RESTful:** Criação de rotas, mapeamento de verbos HTTP e uso de anotações essenciais (`@RestController`, `@RequestMapping`, `@GetMapping`, `@PostMapping`, etc.).
- **Persistência de Dados:** Integração com bancos de dados relacionais e não-relacionais.
- **Testes de Endpoints:** Validação de rotas e payloads utilizando ferramentas como Insomnia.
