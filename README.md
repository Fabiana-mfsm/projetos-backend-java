# Introdução ao Desenvolvimento Backend com Spring Boot

Repositório de estudos práticos desenvolvido a partir da aula de nivelamento e introdução ao ecossistema Spring Boot. Este projeto tem como objetivo consolidar os fundamentos essenciais para a construção de APIs RESTful robustas e escaláveis utilizando a linguagem Java.

---

## Objetivo do Repositório
Servir como guia de referência rápida cobrindo desde os conceitos teóricos do ecossistema corporativo Java até a estruturação prática de um projeto executável conectado a um servidor web embutido.

## Tecnologias e Ferramentas Utilizadas
* **Linguagem:** Java (JDK atualizado / compatível)
* **Framework:** Spring Boot & Spring Web
* **Gerenciador de Dependências:** Apache Maven
* **Servidor Embutido:** Apache Tomcat (embutido no Spring Boot)
* **IDE:** IntelliJ IDEA
* **Cliente de Testes HTTP:** Insomnia

---

## Estrutura de Conteúdos
* **Configuração Inicial:** Geração de pacotes via *Spring Initializr*, definição de metadados (*Reverse Domain*) e inclusão de dependências essenciais (`Spring Web`, `Spring Data MongoDB`).
* **Resolução de Ambiente:** Configuração correta de SDK e compiladores na IDE IntelliJ.
* **Fundamentos de Arquitetura:** Entendimento do ciclo de vida da aplicação e servidores web nativos.
* **Criação de Endpoints:** Desenvolvimento de controladores REST utilizando anotações nativas (`@RestController`, `@RequestMapping`, `@GetMapping`).
